# Lessons Learned

Living log of things that went wrong or surprisingly right, and the rule they produced.
Generic lessons (not tied to this project) are tagged **[KIT]** and get promoted into the
`project-kickstart` plugin during the retrospective.

| Date | Context (task / conversation) | What happened | Rule / fix adopted | Scope |
|---|---|---|---|---|
| 2026-10-26 | Project Kickstart Discovery | Target apps use Rust native GUIs (`iced`, `egui`, `Slint`) rendered via `wgpu`/`winit` rather than HTML DOMs, and user requires hands-free testing without stealing mouse/keyboard focus. | Designed 3-tier non-intrusive actuation (UIA patterns → `PostMessageW` to `HWND` → optional `ui-qa-sdk` named pipe) + background `Windows.Graphics.Capture` / `PrintWindow` instead of foreground `SendInput`. | project |
| 2026-10-26 | M0.3 UIA Spike (`crates/probe`) | Calling `IUIAutomationElement::GetCurrentPattern(UIA_InvokePatternId)` on structural/non-client Win32 elements (`Window = 50032`, `TitleBar = 50037`) triggered a 2,013 ms MSAA proxy timeout. | Filter `GetCurrentPattern` queries by interactive `UIA_ControlType` IDs (`50000`, `50002`, `50005`, `50007`, `50011`, `50013`, `50019`, `50025`, `50031`), reducing UIA walk latency from `2023.0 ms` to `10.14 ms`. | [KIT] |
| 2026-10-26 | M0.2 Capture Spike (`crates/probe`) | Rust 1.99 clippy enforces `clippy::chunks_exact_to_as_chunks` under `-D warnings` when iterating over BGRA pixel buffers by 4 bytes. | Use `bgra_buf.as_chunks_mut::<4>().0` instead of `chunks_exact_mut(4)` for zero-warning RGBA swizzling. | [KIT] |
| 2026-10-27 | Live QA on `MagicBridge` (`eframe`/`egui` 0.31) | `eframe` AccessKit exposes interactive widgets 2–5 levels deep inside structural `Pane`/`Group` nodes, and `PostMessageW(WM_LBUTTONDOWN)` expects client-area coordinates rather than `GetWindowRect`-relative window coordinates (which include the 8px DWM border and 31px title bar). | Walk `IUIAutomation` subtrees up to depth 5 (skipping `TitleBar = 50037` and `MenuBar = 50010`), and subtract `ClientToScreen((0,0)) - GetWindowRect` in `window_rel_to_client_coords` before posting mouse messages. | [KIT] |
| 2026-10-27 | MagicBridge & SonyBridge RFCs | Re-clicking an already-selected TabItem (`50019`) or RadioButton (`50013`) yields zero visual diff (`dHash == 0`) and zero log lines, falsely triggering `UX-DEAD-BTN`. | Query `UIA_SelectionItemPatternId` and `UIA_TogglePatternId` to populate `ui_el.is_selected`, and suppress dead button warnings when re-clicking an already selected or idempotent control. | [KIT] |
| 2026-10-27 | DWM Window Bounds Calibration | Windows 11 drop shadow margins (~8px) skew `GetWindowRect` offsets relative to visible client content. | Call `DwmGetWindowAttribute(DWMWA_EXTENDED_FRAME_BOUNDS)` to extract true visible window bounds, falling back to `GetWindowRect`. | [KIT] |
| 2026-10-27 | Multi-HWND Embedded Views (Tauri/WebView2) | Embedded web renderers (`Chrome_RenderWidgetHostHWND`) ignore input messages posted to the outer parent HWND. | Target the inner render widget directly and translate screen points via `ScreenToClient(render_hwnd)`. | [KIT] |
| 2026-10-27 | Background Process Teardown for Tray Apps | Hardware tray apps minimize to the system notification area on window close, leaving daemon subprocesses alive. | Support `teardown_strategy = "force_kill"` via `taskkill /F /T /PID` to guarantee complete process-tree termination. | [KIT] |
| 2026-11-01 | Consolidated QA from MagicBridge, SonyBridge & TheDognutCorner | QA tools had blind spots: (1) missing font glyphs / tofu boxes ('\u{FFFD}' and '□') were reported as 0 defects; (2) testing at arbitrary window sizes missed clipping occurring at the real default launch size; (3) synthesising unmeasured data (e.g. scancodes) produces fabricated QA reports; (4) headless invariant tests pass while dark-mode visual regressions remain unspotted. | (1) Added `VIS-GLYPH-TOFU` deterministic heuristic; (2) Always capture at target default launch window size; (3) Ground hardware claims strictly in raw unmapped events; (4) Pair headless invariant tests with real-browser/wgpu visual screenshot audits. | [KIT] |
| 2026-11-02 | Issue Audit & Concurrency Safety | Win32 window callbacks (`WNDPROC`) using `static mut` suffer race conditions under multi-threaded test runners. `IUIAutomationInvokePattern::Invoke` falling through to `PostMessageW` caused duplicate click events. | Store telemetry pointers in `GWLP_USERDATA` on `WM_NCCREATE`; return immediately on successful UIA pattern invoke without falling through to Win32 mouse messages. | [KIT] |
| 2026-11-02 | Process Lifecycle & Orphan Prevention | Target processes spawned by `Child::spawn` can orphan child processes if the QA orchestrator crashes or is aborted. | Assign spawned processes to a Win32 Job Object with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE` so the OS terminates the entire process tree on handle close. | [KIT] |
